# SwiftUI Weather App

A simple, elegant SwiftUI weather app showcasing layout, styling, and component-driven architecture. The app demonstrates gradient backgrounds, typographic hierarchy, reusable components, and SF Symbols for weather conditions.
## Features
- Gradient background with layered content using ZStack
- Current conditions with temperature, summary, and high/low
- Hourly forecast strip with icons and temperatures
- Reusable, composable SwiftUI views
- Clean, accessible typography and contrast

## Requirements
- Xcode 15 or later
- iOS 17 or later (can be adapted to earlier versions if needed)
- Swift 5.9+

## Getting Started
1. Clone the repository.
2. Open the project in Xcode.
3. Build and run on a simulator or device.
